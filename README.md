# GRIT指導学院 総合管理・コミュニケーションシステム (v4)

GRIT指導学院の運営業務（校舎・生徒登録、受付・本部アカウント多段階承認登録、授業コマ管理、指導報告書作成、日付指定付き欠席・振替確定、通帳画像OCRによる未入金管理）とLINE連携を統合したWebアプリケーションです。

## 主な追加・強化機能
1. **欠席リスケの日付入力・確定モーダル**
   - 本部管理者・受付スタッフが「振替日入力・確定」を押すと、振替日・開始/終了時刻・担当講師を指定して確定でき、生徒の授業予定表（スケジュール）および保護者・生徒マイページの申請履歴へ即時反映されます。
2. **別枠での受付者・本部アカウント新規登録＆全本部アカウント許可制**
   - 本部管理画面の専用タブ「受付・本部アカウント新規登録・承認」にて、受付スタッフ・本部アカウントの新規登録を別枠で管理できます。
   - 受付スタッフ（Staff）または本部管理者（HQ）を増やす際は、申請者以外の**他の本部アカウント全員の許可**が揃った時点で正式に有効化されます。
3. **多層セキュリティ対策**
   - 全パスワードのソルト付きSHA-256暗号化保存、ログイン試行回数制限（5回失敗で60秒ロック）、30分無操作自動ログアウト、XSSサニタイズ、サーバーレスAPIのタイミング攻撃耐性認証・レート制限を完備しています。
